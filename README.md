# README

## アプリケーションURL
https://new-portfolio-eqo4.onrender.com/

## 🛠️ 使用技術（テックスタック）

### 💻 バックエンド / フロントエンド
* **Ruby** 3.2.10
* **Ruby on Rails** 8.1.3
  * 認証機能: `bcrypt` (has_secure_password)
* **CSSフレームワーク**: Tailwind CSS

### 📊 データ可視化
* **Chartkick**: トレーニング記録の推移や、部位別の割合等を視覚化するために導入。
* **Google Charts**: Chartkickの裏側で動くグラフ描画エンジンとして使用。

### 🗄️ データベース
* **開発環境**: SQLite3
* **本番環境**: PostgreSQL

### 🚀 インフラ / 💡 開発ツール
* **ホスティング**: Render
* **バージョン管理**: GitHub
* **テスト / デバッグ**: RSpec, debug gem
